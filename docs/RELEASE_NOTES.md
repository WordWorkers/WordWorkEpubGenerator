Word Work EPUB – builds EPUB 3 books from texts written in Word Work, for
macOS, Windows and Linux.

**Which file?** Mac with Apple chip → `macOS-AppleSilicon.dmg` · Mac with
Intel → `macOS-Intel.dmg` · Windows → `Windows-x64-setup.exe` · Linux →
`.deb`, `.rpm` or `.AppImage`.

The apps are not signed by Apple/Microsoft: the first start needs one
confirmation (macOS: *System Settings → Privacy & Security → Open Anyway*;
Windows: *More info → Run anyway*). Checksums of all files are in
`SHA256SUMS`.
